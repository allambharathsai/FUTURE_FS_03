# ALLAM'S FAMILY RESTAURANT

Premium static restaurant website for ALLAM'S FAMILY RESTAURANT in Chirala, Andhra Pradesh.

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript

## Features

- Dark theme design
- Loading screen
- Sticky responsive navigation
- Hero animations and parallax
- AOS scroll reveal animations
- Animated counters
- Menu category filtering
- Featured dishes
- Masonry gallery with lightbox
- Testimonials carousel
- Reservation form validation
- Contact cards and Google Maps placeholder
- WhatsApp floating contact button
- Scroll-to-top button
- SEO and Open Graph meta tags
- Lazy-loaded images
